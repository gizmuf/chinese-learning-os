# Lesson UI contract

Use the established Intensive Course lesson list, numbering and quiet light surfaces. New material should reuse the same information structure: overview, lesson journey (examples and vocabulary), independent checks, downloadable materials. Topic visuals support the journey rather than introducing a second navigation system.

- A vocabulary item appears once. Put Listen and Write beside that item. A selected card uses a subtle border/tint; reserve dark primary buttons for primary actions.
- Put a complete example sentence directly after its explicit selector. Do not duplicate a vocabulary-only card under a sentence heading.
- Selection buttons contain plain text. Underlined Chinese text opens the dictionary. Never describe dictionary links as example selectors or nest action buttons inside a selector.
- Pinyin, translation and meaning chunks are independent display controls. Preserve the exact source sentence when splitting chunks.
- Narrative routines read vertically, with semantic illustrations. Show a clock only when a time is stated; show durations as durations, and dayparts as approximate overlapping ranges. Do not substitute “time not specified” for an action label.
- Keep the shared toolbar compact: language menu, two visibly distinct Hanzi examples, component highlight only in the stroke mode. Keep accessible names, keyboard focus and usable touch targets.
- Exploration, listening and supported writing do not create independent review grades. Preserve existing lesson/activity IDs and progress.

November 4 implementation: Lesson 12 vocabulary/example pairs with decorative pictures + contextual checks; reference time lesson morning/class stories and daypart bands; shared compact appearance/language controls. Other lesson structures remain intact.

Lesson 12 follows Lessons 6–8 directly: Overview, numbered Lesson journey, Short checks, PDF materials. Each vocabulary card uses the standard whole-word StudyText dictionary target, Pinyin, translation, Listen and Write. Its authored sentence appears beside it on desktop and immediately beneath it on mobile. Illustrations are small and decorative. No scene-selector cards, comparison mode or per-character annotation renderer. Existing legacy links open the corresponding journey topic.

Shared Writing Studio offers Whole word / One character using the same per-character strokes and completion state. Tablet/desktop starts with whole-word fields for 2–6 character expressions; phone starts with one field. Switching layout never clears the draft. All characters must be completed before comparing/saving; missing stroke data still blocks guided completion. Pencil-only pointer filtering applies to field selection as well as ink.

Writing opened from another surface keeps an explicit Back to learning material action and a local return URL/view/scroll position. Non-review writing has an explicit word/mode/layout route; reloading it must restore that word instead of resuming an unrelated recognition review from the bare root URL. The notebook's visible whole-word model in Stroke appearance uses the same SVG stroke data as its trace guides, and disappears under Hide guides.

The shared dictionary uses one order for words and nested characters: headword/actions, highlighted source sentence, expression/character structure, extra examples. Write is available for every Hanzi expression; Atlas is offered whenever the shared route resolver has a destination. Source audio is resolved from the exact shared lesson entry, including Lesson 12. The close control uses a subtle keyboard focus ring; the resize grip is a curved corner. Lesson 12 can annotate authored character readings directly below each glyph; unsupported alignments retain the full Pinyin line, and the existing Pinyin toggle hides both forms.

Dictionary Notebook is an additive pane in the same definition window. Opening it preserves the right edge and moves the definition left; eight moderate squares appear to the right (two columns when narrow). It reuses Notebook grid/model and Ink/Pencil handling. Selecting another character or folding the pane retains temporary ink until the definition is closed; clearing one square affects only that square. This is supported scratch practice, has no grading action and writes no SRS events. Compact window preferences are preserved separately from the expanded pane.

My lessons retains the existing cards and adds a small Cards/Notebook view switch beside the result count. Notebook rows keep each word card next to whole-word writing repetitions; narrow layouts stack each card with its own notebook. Offscreen canvases are unloaded, while their row state remains; committed ink is stored under practice-book-ink keys in the existing owner-scoped drafts store. The temporary dictionary pane still does not save scratch ink after closing its definition.

A bookmark-plus action on word cards and the shared dictionary adds/removes words or individual Hanzi to Selected for practice. Sentence entries are excluded. The owner-scoped practice-book:v1 draft is updated transactionally so simultaneous tabs merge their changes. This set and its notebook ink are device-local, not independent SRS grades. Existing item IDs, events and review scheduling are unchanged. Appearance preferences persist locally; Print opens contextual writing in Copy and supplies a print notebook model. Stroke animations and stroke-order checking remain available in Stroke appearance through Watch/Trace. Print Trace uses the printed font as a faint reference and constant-width pen ink; it is free tracing, without automatic stroke-order scoring, and always counts as assisted practice. Native browser Back restores the originating library query and filters as well as the in-app return action.

The dictionary mini notebook suppresses selection/callout only within the writing pane (including cell labels), silently rejects palm contacts in Pencil-only mode, and leaves definition text selectable. Whole word / One character preserves separate scratch pages. A two-character word repeats as adjacent pairs; a recorded whole-word pronunciation can provide that word choice from a single-character definition. Main notebook Print models and trace ghosts use the same printed glyphs. Ink rendering changes never rewrite stored stroke points.

Often confused uses the global full-dictionary resolver, regardless of the current HSK filter, including nested character lookups and source sentence context/audio. The library has a direct entry; contrast group IDs are addressable in the URL and browser history restores them. Missing remote content reports real loading/error/no-entry states rather than an HSK placeholder; available words can still be split into characters.

The existing dictionary adds an inline Follow a connection section after character structure: Character families, Related words and In lessons. Families use the full available dictionary's recursive IDS relationships, with selectors for attested shared parts and no HSK/result cap; UI pages eight entries. Existing mapped-stroke highlighting and Print appearance are reused. Shape links do not imply shared meaning or historical origin. Related words use the broad headword list with lesson vocabulary first; at most three visible-page definition requests run together. Every result opens through the existing dictionary navigation rather than a new Atlas screen.

In lessons searches the exported authored occurrence corpus across available course lessons, reference lessons, Shuoshuo, My day and library words/examples. Results retain stable source/lesson identities and exact available recordings; identical text in different lessons keeps each location. Five results per page and a lesson filter keep the popup manageable. The query helpers return all matches for future contextual tools. Word occurrences are not labelled as source sentences. Existing user progress, SRS events and private storage are unchanged.

Exploration tab, selected character/part, page and lesson filter survive nested lookup/back until the definition closes. Back restores the previous source sentence, including an explicitly absent source, and retains curated source audio where available. Existing main definition, breakdown, examples, Write and Notebook actions remain in place. Lesson 12's three independent reading toggles use a compact transparent row with small switches and full label touch targets.
