# Intensive Course lesson 10

2 November 2026. Normal Course route: `/?course=intensive&lesson=10`.
Source: eleven classroom photos plus the supplied short video, transcribed by
the existing lesson content author. The handoff lives in `data/lesson10` with
per-entry source references and explicit uncertain board marks. This is app
lesson 10; no textbook chapter number is inferred.

104 expressions and 39 sentences/quantity phrases are grouped into eight steps:
electronics, comparisons, guessing/age, family, dates, location, actions and
classifiers. The lesson reuses Course progress, independent reading checks,
assisted sentence builders, speaking models, shared word/character lookup,
contextual writing and Today review. Ambiguous bare 干 readings are taught in
the journey but excluded from independent visual checks without disambiguation.
The optional classroom saying is identified as cultural material and is not
scored. Incomplete personal answers and unclear numbers are not invented.

The content handoff is English; other interface languages explicitly retain
English lesson content pending reviewed translations. Audio is restricted to
existing files whose exact text, reading and SHA-256 are verified in this local
source. No TTS requests or provider changes are part of this integration.
Listening checks exist only for these recordings. Missing clips are not exposed
as playable controls.

The approved compact 11-page English study PDF and 36-page English handwriting
PDF are available from the lesson's PDF materials tab. The two verified originals
are retained under `resources/lesson10` in the existing public source repository;
they are not copied into the already near-capacity Sites archive. The same-site
download route uses an explicit file manifest, a pinned public source commit,
exact size/SHA-256 verification and PDF download headers. No learner authentication
or private chat attachment is required. It reuses the public repository source
pattern already used by the dictionary; it creates no R2 binding or provider key.

The manifest supports additional reviewed language/type entries without another
route. This English pair is not the complete standard four-language package.

the remaining Lesson 10 language outputs are being prepared by the existing PDF
