# HSK3 grammar

Additive module at `?grammar=hsk3`, reachable from the HSK3 vocabulary library. Existing Atlas, classroom lessons, levels, writing and account routes stay intact. Twelve thematic units are aligned with the official HSK November 2025 syllabus (effective July 2026), grammar PDF pages 392–394. Original concise teaching cards cover core constructions with EN/FR/RU explanation, Chinese/pinyin example and translated meaning; each has two contextual multiple-choice exercises with corrective explanations. This is a growing teaching module, not a claim that every syllabus subcase has an independent lesson.

Sources: `data/grammar-hsk3-a.json` and `-b.json`. Stable unit/card/exercise IDs; zero external generation at runtime. Options must contain one answer consistent with the localized prompt; feedback is unavailable before checking. Navigation supports skipping, previous/next and horizontal touch swipes; drafts preserve each selected answer. Practice is explicitly guided, because explanations/examples are visible. It never earns independent vocabulary/Atlas FSRS credit.

Exercise drafts use the existing owner-scoped IndexedDB notebook (`grammar-hsk3-v1`). Saved only on this device, as labelled; no new server schema or false cloud-sync claim. Reads/writes guard account transitions. Existing account providers, audience and history tables are unchanged.
