# Scoped UX audit — 26 October 2026

The user reported confusing Atlas navigation, hidden earlier prototypes, sparse labels and iPad writing regressions. This audit addresses those paths, not a claim that every app state has been audited.

## Inventory retained

All nine Atlas routes remain available: Family journey, Cloud map, Family + context, Full path, Space + cards, Word families, Layer map, Family constellations and Repetition matrix. The existing default, route parsing, card animation, recognition flows and lesson content are retained.

Family journey is the recommended first pass for vocabulary with pinyin/meaning/audio. Space + cards is the complementary visual comparison route. Matrix is a word/character presence table, not an achievement score; dots show occurrence. Constellations show repeated characters in the selected vocabulary, rather than claiming a historical or phonetic family.

## Narrow repairs

- Each active view now explains what its elements mean. A disclosure recommends two starting points and lists six earlier design references.
- The original prototype files are copied to `public/design-references/` with a clear sample/no-progress banner and a return link. Multi-variant prototypes receive a standalone selector because their original selector was supplied by the conversation visualization host. Their sample data and designs remain isolated from learning progress. The archive may use earlier Polish labels and earlier colors.
- Hybrid word cards and matrix row labels show pinyin and meaning directly; constellation nodes and matrix columns expose readings. Metadata sizes are aligned in these touched views. This is not a global typography redesign.
- Lesson 5 writing has a searchable topical picker and adjacent character context; shared input handling addresses selection and competing contacts.

## Remaining product decisions

Do not collapse or remove views automatically. First compare Family journey and Space + cards with learners. Global navigation simplification, a universal learning dashboard, complete typography unification, and a single review inbox across all modules remain separate changes requiring their own acceptance criteria. The original prototypes are references with sample data, not alternative fully functioning courses.

## Regression boundary

No auth, billing, permissions, HSK corpus or existing lesson PDF edits. Existing card/cloud animations are not rewritten. The independently published version-42 short-mouse-drag repair (9385c749) is included as the release base. This release preserves older views and adds guidance rather than another Atlas layout.
