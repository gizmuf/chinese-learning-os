# A morning with Shuoshuo

The full built-in lesson opens at `/?lesson=shuoshuo-morning`, from My lessons, and from StudyStudio. It opens directly for guests and signed-in learners. No file selection, download or manual import is required. This is the user-requested normal in-app delivery of their supplied study text; it supersedes file-only delivery for this particular lesson.

`data/shuoshuo-morning.json` is an exact copy of the prepared user-supplied artifact (SHA-256 `82954ce61e4663f5b9e7fff1a2122c804637c7f268a2bda7fd62f02564e069e8`). It retains 65 ordered raw source segments, 42 reading groups, source mapping, all pinyin/English, uncertainties and 40 vocabulary references. There are 34 exact existing vocabulary identities and six lesson-only complete expressions; shorter words do not replace those expressions. The 30 added CSV-derived words were selected from the existing vocabulary export at commit `3edd44de6448acbf5028014710ba99e3d004d2d7`, not a second generated CSV. It does not turn all 237 raw export entries into graded cards.

The UI identifies the Shuoshuo source video, preserves its official link, states that wording/pronunciation have not been verified against audio, and includes CC-CEDICT/MDBG CC-BY-SA 4.0 attribution and contextual vocabulary notes. Disfluent source 48, supplied `ǹg`, the 水泡 segmentation join and conflicting times remain explicit. No new recordings or TTS calls are added.

The lesson uses the existing owner-specific IndexedDB `drafts` store, including the guest notebook, for ungraded reading/writing checkpoints. It shares the exact-content key with the optional local-file reader so a prior import of this exact artifact resumes the same checkpoint. Normal opening does not mutate the private-library catalogue, learning events, grades or FSRS schedules. Existing source versions and other progress remain intact. Lease/revision checks prevent stale-tab overwrites. Account changes cancel pending operations and hide the previous checkpoint.

Reading reveals Hanzi → pinyin → English, supports jumping between all 42 groups and inspecting raw IDs/text. Exact known words use the existing SharedWriting Watch/Trace/Copy/Recall controller with audio disabled and a local ungraded save adapter; Back returns to the same group/reveal. Unknown complete expressions stay reference-only.

Validation includes exact artifact integrity, coverage/counts/provenance, immediate guest opening without import UI, reveal/navigation/reload, writing modes/Back, owner switching, reuse of a prior exact-content checkpoint, preservation of the private catalogue, stale leases and zero learning events. Browser QA covers both entry points, direct opening, mobile width 390 px, reveal, Recall, Back and horizontal overflow. Physical iPad/Pencil behavior remains untested.
