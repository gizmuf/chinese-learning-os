This unmodified downloadable dictionary snapshot is mirrored here so ChineseOS
can resolve arbitrary terms reproducibly without a paid API or transmitting
learner sentences to another service. Source snapshot SHA-256:
`31b9443682a1c0da94f8d4d296f58c2f989313ee26e64fb862336e6d3c84c486`.
The original header retains its publication and attribution metadata.

The runtime fetches this compressed source from an immutable revision of this
existing public repository. It is not bundled in the Sites deployment archive.
The server cache holds source text; positive entry results are cached on device.
The headword index is a derived CC BY-SA 4.0 resource under `public/dictionary/`.
